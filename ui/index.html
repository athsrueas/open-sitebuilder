Cloudflare Pages

Create a Direct Upload Pages project in your account. Use an API token with Account → Cloudflare Pages → Edit permission, restricted to your account. Step-by-step setup and security guide.

Saving encrypts Cloudflare settings for your Windows user account. No .env file is required. If an existing .env contains Cloudflare settings, saving imports them securely and removes those entries. Leave the token blank to keep the existing token.

Pages Edit can modify or delete Pages projects in the permitted account. Keep the token private and revoke it in Cloudflare if exposed. Windows encryption does not protect against malware running under your login.
